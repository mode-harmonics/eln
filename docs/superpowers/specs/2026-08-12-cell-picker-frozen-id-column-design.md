# 电池挑选表冻结编号列设计

## 问题

挑选与分配电池页面虽然为电池编号列声明了 `sticky left-0`，但表格使用 `border-collapse`。横向滚动时，折叠边框表格对 sticky 单元格的定位和绘制层级不稳定，导致编号列随内容移动。

## 方案

- 表格改用 `border-separate border-spacing-0`，为 sticky 单元格提供稳定的定位盒。
- 电池编号表头固定在 `top-0 left-0`，层级高于普通表头和数据单元格。
- 电池编号内容固定在 `left-0`，使用不透明背景和右侧阴影，避免滚动内容透出。
- 右侧“分配测试类型”固定列保持不变。
- 不修改数据加载、选择、分配或提交逻辑。

## 验证

- 前端 TypeScript 检查通过。
- Vite 生产构建通过。
- 检查生成的 DOM 类名确保表格使用分离边框且首列具有固定定位、左偏移、背景与层级。
